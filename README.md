# US-Treasury-Macro-Project
A macro research project analyzing the impact of Fed monetary policy on the US Treasury yield curve from 2000 to 2026.

DISCRIBTION

This project aims to analyze the relationship between the U.S. Treasury yield curve (10-year minus 2-year spread) and the Federal Funds Rate. The project workflow involves loading and cleaning historical data from T10Y2Y.csv and FEDFUNDS.csv. The analysis specifically focuses on data from 2022 to the present, encompassing missing value imputation, calculation of the correlation coefficient between these two key financial indicators, and visualization of their trends via a dual-axis chart. The primary objective is to gain deeper insights into how these critical macroeconomic variables interact, particularly during periods marked by significant economic events such as interest rate hikes.
